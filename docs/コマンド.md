# コマンド一覧

## Cursor で使う

チャットの **`/`** メニュー（または **`/push`** などと入力）から、`.cursor/commands/` に対応するコマンドを選ぶと、エージェントが `npm run` で実行する。一覧はこのファイル。

## `/push` — Git へ上げる

ローカルの変更を **ステージ → コミット → `origin` へ push** まで一度に行う。コミットメッセージは省略可（差分から自動生成）。

## `/blazecrown` — 最新情報の調査

**公式サイト・攻略Wiki・公式X（@BLAZECROWN_JP）**を取得し、β日程・告知・キャラ追加などの**最新情報を要約**する。必要なら **`--sync`** でキャラデータも更新する。

## `wiki:sync-characters` — 公式Wiki同期

公式攻略Wikiからキャラ情報を取得し、`character-wiki.json` を更新する。

## `dev` / `build` / `preview` — サイト開発

ローカル表示・本番ビルド・ビルド結果の確認を行う。

## `seo:verify` — 検索向けファイルの確認

`robots.txt` とサイトマップが正しく配信されているか確認する。ビルド直後は `npm run seo:verify -- --local`、本番は `npm run seo:verify`。Search Console の登録手順は実行ログ末尾に表示される。
