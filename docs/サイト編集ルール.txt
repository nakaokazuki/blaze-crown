# BLAZE CROWN 非公式サイト — 編集ルール（必読）

最終更新: 2026-11-23
対象: blaze-crown.com（Astro SSG）および本リポジトリ一式

【重要】このファイルを編集・記事追加・デプロイ前に必ず読むこと。
AI・人間とも、作業開始時に本ファイルを開き、該当セクションを確認してから手を動かす。

────────────────────────────────────
§0 絶対ルール（短く）
────────────────────────────────────

1. 変更は最小範囲。依頼と無関係なファイルを触らない。
2. 新規攻略はまず下書き。確認後だけ guides/ に置く（§2）。
3. 公開済み URL（slug）を削除・リネームしない。必要ならユーザーに確認。
4. 公式 Wiki・公式サイトと矛盾する記述を断定で書かない。一次ソースは docs/ゲームルール.txt。
5. push 前に git status / git diff を見る。npm run push は全体ステージになる（§6）。
6. 記事・レイアウト変更後は npm run build で確認（可能なら npm run seo:verify）。

────────────────────────────────────

────────────────────────────────────

| 種類 | パス | 備考 |

────────────────────────────────────
§2 記事（MDX）の作り方
────────────────────────────────────

■ フロントマター（必須）

  title, game, category, tags, publishedAt, updatedAt, description
  featured, related は任意（スキーマ: src/content.config.ts）

■ title / description

  - showLead: false … description は meta のみ。本文ヘッダーのリード（.lead）を出さない。
  - 検索用は description 先頭に「ブレイズクラウン（BLAZE CROWN）」を含めてよい。
  - title が長すぎる場合も、タブには「| BLAZE CROWN」が付く（BaseLayout）。
  - 非公式であることは description または本文で明示。

■ 日付

  - publishedAt: 初回公開日。updatedAt: 本文を実質変更した日（虚偽更新しない）。

■ コンテンツ方針（β期間）

  - 新規は「デッキ最強・性能評価の断定」を増やさない（調整後に無効になりやすい）。
  - 既存デッキ記事を残す場合は β 時点の記録である旨を書く。
  - 1位体験記・プレイメモ・β制度まとめ・イベントなど体験・事実系を優先。
  - 公式の言い換えだけの用語辞典・初心者ガイドは優先度低（公式 Wiki あり）。

■ 下書き → 公開の手順

  1. content/drafts/guides/ に .mdx を作成
  2. npm run build（下書きはビルド対象外のためエラー源にならない）
  3. ローカルプレビュー: npm run dev → http://localhost:4321/drafts/<slug>/
     （noindex・サイトマップ除外。本番にも /drafts/ は出るが検索非推奨）
  4. 内容・frontmatter を確認
  5. content/games/blaze-crown/guides/ にコピー（slug 確定）
  6. 再度 npm run build
  6. 本番後は GSC URL 検査（未登録時のみインデックス登録をリクエスト）

────────────────────────────────────
§3 AI・自動生成で触ってよい範囲
────────────────────────────────────

■ 1タスク = 原則1ファイル（またはユーザーが指定したファイルだけ）

■ 触らない（明示指示がない限り）

  - 他の guides/*.mdx
  - package.json / astro.config / CI 設定
  - supabase/migrations（スキーマ変更は別タスク）
  - .env（秘密情報）

■ 記事追加で時々触る src（必要時のみ）

  - src/pages/games/[game]/guides/[slug].astro … 記事専用目次
  - src/lib/betaTestGuideToc.ts / betaRank3DeckToc.ts … 目次定義
  - src/lib/characterDeckRecommendations.ts … キャラ→記事リンク

  新記事で目次・キャラリンクが不要なら src は変更不要。

§4 Git / デプロイ
────────────────────────────────────

- コミットはユーザーが依頼したときのみ。

- force push・git config 変更は禁止（ユーザールール）。
