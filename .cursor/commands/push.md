# `/push` — Git へ上げる

ローカルの変更を **ステージ → コミット → `origin` へ push** まで一度に行う。

## エージェントの手順

1. リポジトリルートで実行（`git_write` と `network` が必要なら要求する）:
   - メッセージなし（推奨）: `npm run push`
   - 明示する場合: `npm run push -- "コミットメッセージ"`
2. メッセージ省略時は `push.sh` が差分から**日本語の1文を自動生成**する。
3. 成功・失敗と、使われたコミットメッセージを簡潔に報告する。

実体: `scripts/push.sh`／説明: `docs/コマンド.md`
